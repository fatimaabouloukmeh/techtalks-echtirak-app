# Ishtirak Management System

A web-based subscription management system developed as part of the TechTalks Internship.

## Project Overview

The system aims to simplify subscription management, meter readings, billing, payment recording, and balance tracking.

## Project Goals

- Manage subscribers.
- Organize subscription tariffs.
- Record meter readings.
- Calculate bills.
- Track payments and outstanding balances.

## Project Status

Initial Setup – Technology Selection and Planning in Progress.
